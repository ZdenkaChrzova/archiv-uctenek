# Archiv účtenek

Soukromá PWA pro ukládání účtenek, faktur a záručních dokladů. Data a přílohy jsou uloženy lokálně v IndexedDB daného prohlížeče.

## Publikování na GitHub Pages
1. Nahrajte všechny soubory z tohoto balíčku do kořene repozitáře.
2. V GitHubu otevřete Settings > Pages.
3. Jako zdroj vyberte větev main a složku /root.
4. Uložte nastavení a po zveřejnění otevřete adresu webu.

Důležité: pravidelně v aplikaci používejte Export zálohy.
